# Ventsistema

Statinė svetainė: HTML, CSS, JS be išorinių paslaugų. Puslapiai: pradžia, paslaugos, objektai, kontaktai, privatumo politika, 404.

Bibliotekos vendor/ kataloge: GSAP 3.15.0 ir Three.js 0.186 (MIT). Šriftai: Bricolage Grotesque ir Onest (OFL), fonts/ kataloge.

Peržiūros versija (GitHub Pages) neindeksuojama. Galutinė versija domenui ventsistema.lt: `python build.py --final` (sukuria ../ventsistema-site-final, šaltinio nekeičia).

Nuotraukos: kiekvienai JPG yra WebP variantai (-s, -m, pilna), rodomi per <picture>. Pirmo ekrano 3D paveikslėliai img/rekuperatorius-3d-*.webp nufotografuoti iš js/scene3d.js scenos; gyva 3D scena kraunama tik kompiuteryje.
